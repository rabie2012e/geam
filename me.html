تصميم الشعر · البرمجة

أنا طالب في الصف العاشر، سوداني وأعيش في سلطنة عُمان. بدأت أتعلّم البرمجة لأني أحب أفهم كيف تُبنى المواقع والتطبيقات اللي أستخدمها كل يوم، ومو بس أستخدمها.

وأتعلّم تصميم الشعر كمان — فيه شي مشترك بين الاثنين: كلاهما بناء بقواعد، وكلاهما يحتاج تعيد وتصلّح لين يطلع صح.

أتعلّم لوحدي خطوة خطوة: أقرأ، أجرّب، أكسر الكود، وأصلّحه. وكل شيء أتعلّمه أحاول أطبّقه في مشروع صغير بدل ما يبقى مجرد معلومة.

اللي أتعلّمه الآن

  • ✓ HTML بناء هيكل الصفحة: العناوين، الفقرات، الروابط، الصور.
  • ✓ CSS الألوان والخطوط وترتيب العناصر والوضع الليلي.
  • ✓ JavaScript بنيت فيها لعبة ثلاثية الأبعاد كاملة تشتغل في المتصفح.
  • ✓ Git و GitHub نشرت موقعين على الإنترنت فعلاً — هذا الموقع واللعبة.
